# reels-media

Видео-рилсы @30days.forma на 6–8 ноября 2026 для планирования в Metricool.
Ветка служебная: в ней только mp4-файлы, код платформы — в `main`.
Metricool копирует видео к себе при постановке поста, после этого ветку можно удалить.

Кадры: Pexels (бесплатная лицензия), авторы указаны в подписях к постам.
